About this dataset

This project uses a simulated dataset of 30 e-commerce orders created for educational demonstration. It does not contain real customer records.

  • Currency: Egyptian pounds (EGP).
  • Total orders count each row as one order.
  • Average order value = total order value ÷ number of orders.
  • Average rating = sum of customer ratings ÷ number of ratings.
  • Monthly purchases are counted using the purchase date.
  • Because the data is simulated and limited, findings illustrate the dashboard functions and should not be treated as real market research.
